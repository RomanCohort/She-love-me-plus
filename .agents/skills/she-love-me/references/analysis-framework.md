# 心理学分析框架

本文件定义「她不一样」的 AI 深度分析模块 F、A、B。
执行 Step 7 时按顺序读取并应用。

---

## 模块 F：人格深度画像 🧬（首先执行，是所有模块的基础）

**【核心纪律：无证据不诊断】** 所有心理学推断必须引用带时间戳的原话作为锚点。

### F1. 人格核心特质与核心恐惧 (Core Traits & Core Fear)

从语言习惯推断大五人格，并必须深挖每个人的**「核心恐惧」**（这是决定他们行为模式的真正内驱力）：
- **被抛弃恐惧 (Fear of Abandonment)**：表现为高频确认、需要秒回、过度讨好。
- **被吞噬/丧失控制恐惧 (Fear of Engulfment)**：表现为回避亲密、强调独立、在感情升温时突然消失。
- **被贬低恐惧 (Fear of Inadequacy)**：表现为强烈的自尊心防御、不愿暴露脆弱、吹嘘或防御性攻击。

**语言信号 → 大五人格维度映射：**

| 语言信号 | 推断维度 |
|---------|---------|
| 频繁提到事业/成就/不想虚度/规划未来 | 高尽责性（Conscientiousness）— 事业心强、有目标感 |
| "我觉得""也许""好像""感觉"高频出现 | 高神经质（Neuroticism）— 情绪敏感、内心多虑 |
| 主动分享脆弱后立刻转移话题 | 情感细腻 + 防御性开放 — 渴望被理解但害怕暴露过多 |
| 对对方过去经历/社交异常敏感、反复追问 | 低安全感 + 高嫉妒倾向 — 以质疑作为自我保护 |
| 用逻辑/理性语言解释情感决定 | 理性化防御 — 感情已深，用理智撑门面 |
| 反复要求"你说你真心""你是不是骗我" | 高确定性需求 — 内部工作模型受损，需要反复验证 |
| "我们"高频出现，少用"你和我"分开说 | 高亲和力 — 主动建立共同体感，渴望归属 |
| 聊天以安排事务为主，少有情感表达 | 高尽责性 + 事务导向 — 用行动而非言语表达在意 |
| 大量感叹号、emoji、情感词汇 | 高外向性 — 情感型沟通，需要被看见和回应 |
| 清醒、自我审视，能评价自己的行为 | 高元认知能力 — 有自我觉察，但可能因此更自我挣扎 |

### F2. 防御机制识别（最关键，这是读懂一个人的钥匙）

对每种识别到的防御机制，必须输出：① 防御名称，② 触发情境，③ 聊天中的具体例子，④ 真实含义解码

```
防御性撤退（Protective Withdrawal）
识别信号："我们不合适" / "一开始就是错的" / "算了" / "随便你" / "不想说了"
关键判断：这句话出现在什么情境？争吵后/被忽视后/还是主动说的？
真实含义：情绪低落时的自我保护，不是理性评估。说"不合适"的人往往是在等待被否定——
          如果对方接受了这个说法，那证明对方果然不够在乎；如果对方反驳，才是她想要的回应。

理性化（Rationalization）
识别信号：用逻辑论证"为什么不行"，但实际行为完全相反（例：说"不合适"然后凌晨主动发消息）
真实含义：感情已深，理智上知道有风险，用理性语言撑门面——保护自己不显得太主动、太需要

投射性怀疑（Projective Suspicion）
识别信号："你肯定对别人也这样" / "你来者不拒" / "你之前那个人怎么样"
真实含义：自身安全感不足，把内心的恐惧（"我不够特别"）投射为对对方的质疑
          这不是在攻击，而是在问："我在你心里是不是最特别的那个？"

情感否认（Emotional Denial）
识别信号："我没那么喜欢你" / "无所谓" 但行为显示高度卷入（主动联系、深夜消息、细节记忆）
真实含义：感情深度已经超出她的舒适区，用否认来保护自主感——"是我选择不太在乎，不是我控制不了"

回避型开放（Selective Disclosure）
识别信号：分享了非常私密的事（家庭/过去/脆弱）后突然话题一转或变冷漠
真实含义：在测试对方的反应。一旦感到对方没有给予足够的回应，立刻关门——"我分享了，你没珍惜，是你的问题"
```

### F3. 底层需求 → 表面行为解码（让用户感到「被看穿了」的核心）

对每一个识别到的行为模式，必须解码其背后的底层需求：

| 表面行为 | 底层需求 | 解码要点 |
|---------|---------|---------|
| 反复确认真心/"不相信你" | 高确定性需求，安全感基础薄弱 | 她需要的不是你说"我爱你"，而是时间累积的一致性证明 |
| 提事业/不想被耽误 | 害怕因为爱情失去自我价值感和独立性 | 这是她保护自己「即使失去你也还有自己」的方式 |
| 说你"来者不拒"/"随便什么人都行" | 渴望成为你眼中唯一特殊的那个人 | 她需要的是排他感和被选中感 |
| "路还长，不着急" | 给你证明空间的同时给自己保留退路 | 降低当下的脆弱暴露，但并不代表不在乎 |
| 忽冷忽热、一会热情一会消失 | 高度卷入但尚未决定是否值得全情投入 | 用冷热测试你的耐受力和真心，也在测试自己 |
| 撤回消息 | 说了太多真心话，防御性收回 | "暴露过多"触发了防御，撤回是在重新建立心理安全距离 |
| 说"一开始就是错的" | 情绪低落时的自我保护性撤退，不是真实评估 | 注意：这句话在什么情境下出现？争吵后/被忽视后？ |

### F4. 信任架构分析

基于以上分析，总结该人的信任建立模式：
- 信任的建立需要什么条件（一致性/时间/具体行动/情感回应）
- 什么行为会触发防御反应（被忽视/感到不特别/情感暴露后未被接住）
- 历史经历对当前信任模式的影响（如聊天中有相关线索，必须引用）

### F5. 情感信号强度分级（弱信号 vs 强信号甄别）

**为什么需要这一节**：中文日常客套里，自我贬低、试探、抱怨的**基准发生率极高**——「我最近好累」「我这人就这样」「我的生活没什么值得分享的」在普通朋友对话里都会出现。单凭一句话判定「她在示弱」，是本框架最容易犯的错误。F1–F4 教你**怎么读**，本节教你**怎么筛**：只有通过本节判定的信号，才有资格作为下游模块的证据。

对每一句疑似「示弱 / 试探 / 索取回应」的话，逐轴跑一遍：

```
轴 1 · 停驻性（Stopping Power）——她在停住等你回应，还是说完自己往下说？
  强：说完即止，把话头交给你；或撤回后重发；或长时间"正在输入"后只发出这一句
  弱：紧接着自己补充、自己解释、自己找台阶、自己把话题带走

轴 2 · 复现性（Recurrence）——一次性的，还是短期内反复出现？
  强：同一主题 7 天内 ≥2 次，或换个说法又说一遍（同义变体）
  弱：全量记录中仅此 1 次，且无同义变体

轴 3 · 指向性（Specificity）——指向笼统的「我」，还是具体的「这件事」？
  强：笼统的自我评价（"我这个人" / "我的生活" / "我好像一直"）——越笼统越难用就事论事解释
  弱：具体事件或状态（"这次没考好" / "今天有点累"）——属于状态描述，不是自我评价

轴 4 · 悬置性（Persistence）——你不接这句话，第二天它还在不在？
  强：以别的方式回来（情绪延续、语气变冷、回避同类话题、隔天主动提起）
  弱：第二天完全消失，关系温度无变化
```

**判定规则**：

- 命中 **≥3 轴** → 「强情感信号」，可作为下游证据，`evidence_level` 可给 `high`
- 命中 **2 轴** → 「中等情感信号」，可写入，`evidence_level` 上限 `medium`
- 命中 **1 轴** → 「待观察信号」，只能写进 `observable_signals`，不得单独下结论
- 命中 **0 轴** → 不计入。这是中文日常对话的基准噪音，不得出现在报告中
- **轴 4 无法判断**（消息位于记录末端或采样窗口末端）→ 该轴记「未定」，判定上限压到「中等」，**不得判为强**

**与 `risk-signals.md` 双阈值的关系**：机制同构，两者共享同一条底层纪律——**单一证据不构成结论，证据不足时降级，而不是强行归类**。但**阈值不可混用**：risk-signals 是「量化条件 ∧ 文本条件，两条都满足才高亮」，本节是「四轴命中数决定强度」。不要把本节判定的「命中 2 轴」当成 risk-signals 的「量化条件满足」去触发 C 类预警。

**下游约束**：模块 B5「对方分享过脆弱」、模块 A2「亲密（Intimacy）」的计数，**只统计通过本节判定的信号**；命中 0 轴的自嘲/客套不得计入任何「脆弱分享」；判定为「待观察」的信号，在报告中只能以「值得继续观察」的语气出现，不得写成结论。

**正例锚点**：

```
对方原话（2026-09-21 22:33）："诶呀我的生活没有什么值得分享的"

轴 1 停驻性 → 命中：说完后无任何补充，把话头交了出去
轴 2 复现性 → 弱：全量记录中「值得分享」仅此 1 次
轴 3 指向性 → 命中："我的生活"是笼统自我评价，不是具体事件
轴 4 悬置性 → 未定：该消息位于记录末端，无次日数据

判定：2 轴命中 + 1 轴未定 → 中等情感信号，evidence_level = medium
必须同时标注「缺少次日追踪，无法确认这是持续情绪还是一次性感慨」
```

**反例锚点**（必须掌握，否则本节会被误用成「凡自嘲皆计数」）：

```
对方原话（2026-04-02 22:00）："还不行呢"
（情境：夹在"不对！！"与对方发来的报错截图之间，纯粹是软件调试的状态汇报）

轴 1 停驻性 → 弱：说完即被下一个调试话题带走
轴 2 复现性 → 弱：全量仅此 1 次
轴 3 指向性 → 弱：回应的是具体事务，不是自我评价
轴 4 悬置性 → 弱：次日无任何延续

判定：0 轴命中 → 不计入。这就是中文日常对话的基准噪音。
```

## 模块 A：关系诊断

### A1. 关系类型判断（从以下选择一个最贴合的）

| 类型 | 核心特征 |
|------|---------|
| 【深陷单恋】 | 付出严重不对等，单方面热情，对方享受但不投入 |
| 【相互喜欢】 | 双向奔赴，情感基本对等，有明显互动正向循环 |
| 【暧昧拉锯】 | 都有好感但都在试探，忽冷忽热，关系尚未定性 |
| 【备胎危机】 | 你是备选项，对方同时有其他选择，优先级低 |
| 【情感工具人】 | 你在被利用（情绪价值/实际需求），对方无真实情感投入 |
| 【名存实亡】 | 曾经有感情，现在已经冷透，对话形同陌路 |
| 【朋友边界】 | 纯粹友谊，没有明显爱意迹象 |

### A2. Sternberg 三角理论评估（Robert Sternberg，1986）

从聊天记录中识别以下三个维度的证据：
- **激情（Passion）**：主动追求、情欲表达、憧憬见面、身体性描述
- **亲密（Intimacy）**：分享脆弱、互相倾诉、情感支持、深度理解
- **承诺（Commitment）**：对未来的规划、稳定性表现、危机时的坚持

根据三角形状判断爱情类型：
- 三高 → 完全之爱（Consummate Love）
- 激情高、亲密低、承诺低 → 迷恋（Infatuation）
- 亲密高、激情低、承诺低 → 喜欢（Liking）
- 承诺高但激情/亲密低 → 空洞之爱（Empty Love）
- 激情+亲密，无承诺 → 浪漫之爱（Romantic Love）

### A3. 关系趋势判断

扫描消息时间线，识别整体轨迹：
- **升温中**：近期互动增多、情感词增多、回复速度加快
- **平稳维持**：节奏稳定，无明显变化
- **逐渐降温**：近期消息减少、回复变短、主动性下降
- **已经凉透**：近两周内消息稀疏，对话敷衍

### A3.1 关键时刻时间线（类型化）

A5 的「关键转折点溯源」只找**一个**断崖点。本小节把它升级为**类型化的事件列表**——
不是所有影响关系走向的时刻都是一次「断崖」。

从全量记录中提取值得跨片段保留的时刻，每个时刻标一个 kind（词表见
`intent-taxonomy.md` 第四节，12 种）：

- **里程碑**：`boundary` 拒绝/划清界限 · `reopen` 重新靠近 · `invitation` 邀约 ·
  `confirmation` 确认安排 · `cancellation` 取消安排 · `care` 关心 ·
  `disclosure` 敞开心扉 · `commitment` 表达心意
- **次要**（默认不进主视图，避免淹没里程碑）：`question` 提问 · `correction` 澄清 ·
  `preference` 说出喜好

每条时刻必须带：**时间戳 + 发送者 + kind + 原文引用 + status**（`active` / `resolved` / `uncertain`）。

**两类必须单独点名的时刻**：

- **`boundary`（边界）**：是 `scoring-rubrics.md` 里好感封顶（`boundary_applied`）的触发源。
  检出未撤回的边界 → 总分封顶 25。**「被撤回的边界」不是边界**——若后续有 `reopen`，
  该 `boundary` 的 status 置 `resolved`，不再触发封顶。
- **`reopen`（重新靠近）**：本框架里权重被低估的一类。实测语料中，**一次「自己重新开门」
  往往比十条热络消息更能说明关系状态**——因为它是在没有任何激励的情况下发生的。

**门槛**：时刻的 `confidence < 0.65` 不写入。宁可漏，不可凑。

**与 A5「关键转折点」的分工**：A5 找的是**温度断崖**（一个日期 + 一个事件），
A3.1 找的是**整个事件序列**（含那些没有断崖但改变了关系结构的时刻，如 `boundary` /
`reopen` / `disclosure`）。两者互补，都要写。

### A4. 关系阶段精准定位

当前 7 种关系类型是「截面状态」，还需要在**关系连续谱**上精准定位：

```
初识试探期 → 暧昧升温期 → 拉锯确认期 → 实名化前夜 → 正式确认期 → 关系维护期 → 降温衰退期
```

**「实名化前夜」专项识别**（满足以下 4 条中的 2 条即触发）：
- 双方使用亲昵称呼（老公/老婆/宝宝/亲爱的）
- 有过线下接触或明确的亲密行为描述
- 一方或双方曾明确表达情感（"我会好好爱你"/"喜欢你"/"想见你"）
- 关系从未被正式定义或确认

触发后必须分析：
1. 此阶段的心理动态——为什么「名不正言不顺」会持续消耗安全感
2. 是谁在主动阻止关系正式化，为什么（防御机制）
3. 如何推动关系进入正式确认期（具体建议）

### A5. 情感投入不对称分析

- **对称性评分**（0–10，0 = 极度不对称，10 = 完全对称）
- **谁是「锚」**：更在乎、更主动、更难离开的那个人
- **谁是「浮标」**：更保留、更有距离感、掌握主动权的那个人
- **冲突应对模式**：当关系出现张力时，谁先退缩、谁追上去
- **权力动态量化**：统计话题发起次数与话题终结次数，判断谁掌控节奏。最小兴趣原则：兴趣更低的一方天然拥有更高的关系权力。
- **关键转折点溯源**：扫描全量时间线，找出关系温度发生断崖式变化的具体日期与标志性事件

**⚠️ 硬规矩：「主动」和「回应」是两个独立的轴，分开报，不得压成一个「投入度」。**

这是本模块最容易出错的地方。「ta 从不主动」经常被读成「ta 不投入」——**这两件事可以同时不成立**。实测一份 180 天、1243 条的语料：

| | 他 | 她 |
|---|---|---|
| **发起**（谁开的头） | 85% | 15% |
| **回应**（对方开口后，接得有没有内容） | 67% | 85% |

**两个轴的方向是相反的。** 发起高度单向，回应却是她更高。

所以结论必须写成「**ta 很少主动，但接得住**」这种两句式，不能压成一句「单向投入」。前一句成立，不代表后一句成立——把它们合并，报告就会从「她友好但被动」滑成「她不在乎」，那是两回事。

判「回应」用四类，定义见 `reports/responsiveness_definition.md`：**投入**（给了对方没有的东西——新信息 / 反问 / 具体步骤 / 自己的经历；**讲技术属于此类**）/ **应答**（只接住，内容是对方已确定的）/ **转开** / **没回**。

**另注：「关键转折点溯源」要防噪声。** 同一份语料上，每格抽 10 条的投入率趋势看起来是清晰交叉的（他 7/7/4/5、她 5/8/9/9），扩到每格 30 条后**消失了**（他 23/20/18/19、她 25/24/26/24，两条线基本平行）。**10 个样本一格的趋势，就是掷硬币**——要么别报趋势，要么把每格样本量做到 30 以上。

### A5.1 六维好感度（对方一侧）

`symmetry_score` 量的是**对不对称**，本小节量的是**对方对你有没有好感**。
**两个轴正交，不得互相替代**——完整分工见 `scoring-rubrics.md` 第 1.1 节。

六个维度（权重）：`主动延续`(15) · `回应投入`(20) · `关心体贴`(20) ·
`自我开放`(15) · `亲密表达`(20) · `实际行动`(10)

每维按五档量表评分，**每维必须标注 `basis`（`quant` / `text` / `mixed`）**：

- `basis == "quant"` → 必须在 `derivation` 写明用的是 `stats.json` 哪个字段、哪套口径
- `basis == "text"` → 分数**只能取 0 / 25 / 50 / 75 / 100**（五档锚点值），
  不得给 `72` 这种数字——**没统计底的精值是假精确**

> ⚠️ **唯一有干净统计锚点的是「主动延续」**（`c_metrics.session_gaps`）。
> 「回应投入」的 `turn_response` 是**回复长度代理，不是投入度**；
> 「自我开放 / 亲密表达 / 实际行动」三维**完全没有对应字段**。
> 具体可得性表见 `scoring-rubrics.md` 第 1.4 节。**锚点缺失时不许编数字。**

**总分**：只在 ≥4 维有分时才输出，且要在 `total_note` 里点名哪几维是靠文本推断的。
**边界封顶**：检出未撤回的 `boundary` 时刻（见 A3.1）→ `total = min(25, total)`。

### A6. Gottman 四骑士检测（John Gottman，华盛顿大学）

（这四种模式能以 93.6% 的准确率预测分手/离婚）

- **批评（Criticism）**：攻击人格而非具体行为。例："你就是这种人""你从来都不会关心人"
- **蔑视（Contempt）**：讥讽、嘲弄。这是最危险的信号。例："你真是可笑""算了，跟你说不清楚"
- **防御（Defensiveness）**：反击而非倾听，把责任推给对方。例："那也是因为你先..."
- **冷战/筑墙（Stonewalling）**：彻底关闭沟通，已读不回、"随便""好的"敷衍

**Gottman 5:1 法则**：若正向互动与负向互动的比值低于 5:1，关系健康存疑。

### A7. 修复尝试分析（Repair Attempts）

冷战或争吵之后：
- **谁先低头**：主动发消息的是哪一方，还是双方都假装什么都没发生？
- **修复方式**：发笑话/转移话题/直接道歉/发语音/主动约见面？
- **对方响应**：顺坡下驴，还是继续用冷漠惩罚对方？
- **修复成功率**：识别历史上所有修复尝试的成功/失败比

## 语言模式深度分析（贯穿所有模块）

在阅读聊天记录时，同时进行以下语言学层面的观察：

- **代词使用**："我们"高频出现 → 主动建立共同体感；坚持用"你"和"我"分开说 → 在维持心理边界
- **时态指向**：频繁提"以后/将来/等以后" → 结合是否有具体落地行动判断是真期待还是「未来饼」
- **条件句密度**："如果你能...""要是你...""等你...了再说" → 在设定条件和门槛
- **模糊词密度**："也许/可能/感觉/好像/大概" → 密度越高 → 越不确定/安全感越低
- **情绪词正负比**：积极情绪词 vs 消极情绪词的比例
- **撤回消息**：是情绪失控后的防御性收回还是普通习惯？结合撤回时间和上下文判断
- **话题发起权**：谁更多地开启新话题，谁更多地在回应

## 模块 B：人格深度分析

### B1. 依恋类型诊断（Bowlby 依恋理论，Ainsworth 成人依恋量表 ECR）

对**用户（我方）**和**对方**分别判断依恋类型：

**安全型（Secure）** — 低焦虑 + 低回避
- 聊天信号：能舒适表达需求、不会过度解读对方沉默、争吵后能主动修复、给对方空间但不失联
- 典型语言："我有点担心你，你今天怎么了？" / "我需要一点时间，但我们可以之后再聊"

**焦虑型（Anxious-Preoccupied）** — 高焦虑 + 低回避
- 聊天信号：频繁发消息确认对方在不在、消息没被秒回就发"？"或"你怎么了"、对方语气稍冷就过度解读、深夜倾诉
- 典型语言："你是不是不想理我了" / "你今天好像有点冷漠" / 消息连发 3 条以上未等回复

**回避型（Dismissive-Avoidant）** — 低焦虑 + 高回避
- 聊天信号：对方情感表达后转移话题、回复简短、拒绝深入讨论感情
- 典型语言："嗯" / "好的" / "最近忙" / 主动从不谈感情

**恐惧型（Fearful-Avoidant）** — 高焦虑 + 高回避（又称混乱型）
- 聊天信号：时而热烈时而突然消失、主动靠近后又拉开距离、情绪波动大
- 典型语言：热情后突然"算了，你不懂我" / 撤回大量情感消息 / 忽冷忽热没有规律

**追逃循环（Pursue-Distance Cycle）** — Christensen & Heavey，1990

如果我方是焦虑型、对方是回避型，必须识别并指出：**我越追→TA越逃→我更焦虑→TA更压抑→关系恶化**

**追逃循环闭环复盘**（强制执行）：从聊天记录中找出一次最典型的"案发现场"，还原：
1. **触发事件**：我说了什么，触发了对方的「被吞噬恐惧」（引用原文）
2. **对方撤退**：对方用什么方式逃
3. **我的升级**：面对撤退，我如何加大"追"
4. **关系恶化节点**：此次循环终点，关系温度在此之后的变化

### B2. 沟通风格分析

- **主导型**：频繁发起话题，引导对话方向，习惯给建议
- **迎合型**：多数时候顺着对方，很少主动提出自己的想法
- **情绪型**：大量使用情感词、感叹号，倾向于分享感受
- **事务型**：聊天集中在安排事项、分享信息，少有情感表达
- **爆发型**：平时话少，积压后突然倾诉大量内容

### B3. 情绪调节风格

- **过度表达**：把每个情绪都倾倒给对方（容易让对方感到压力）
- **压抑回避**：从不主动提自己的感受（容易产生误解）
- **健康表达**：能够适时说出感受，也能给对方空间

### B4. 五种爱的语言（Gary Chapman，1992）

识别双方偏好的爱的语言：
- **肯定的言辞（Words of Affirmation）**：夸对方、说"我喜欢你"、给予认可
- **精心的时刻（Quality Time）**：约见面、问"最近怎么样"、深度陪伴式对话
- **接受礼物（Receiving Gifts）**：提到送东西、分享购物、记住对方想要的
- **服务的行为（Acts of Service）**：帮忙做事、主动解决对方的问题
- **身体的接触（Physical Touch）**：提到拥抱/见面/肢体接近的渴望

如果双方爱的语言不同，指出这是常见的"语言不通"误区。

### B5. 情感可得性评估（Emotional Availability）

| 可得性信号 | 含义 |
|-----------|------|
| 对方分享过脆弱/创伤/恐惧，并允许被接住 | 高可得性——有意愿开放自我 |
| 对方在你倾诉时会反问、深入、共情 | 高可得性——有能力接住情绪 |
| 对方总是转移话题、给建议而不是陪伴 | 低可得性——情感处理回路短路 |
| 对方的情感表达随情绪波动，无法稳定给予 | 低可得性——自身情绪调节尚未完成 |
| 对方明确提到"现在不适合谈感情/太忙/要专注自己" | 当下主动关闭情感通道 |

**必须给出结论**：对方目前情感可得性评级（高/中/低）及继续投入的风险提示。

## 模块 H：对话动作分类 🗣️（逐条层）

模块 F/A/B 都在**关系层**判断「这两个人怎么样」。模块 H 下沉到**逐条层**：
**每一条消息在做什么**。它是验证层——关系层的结论如果与逐条动作矛盾，要回头查关系层。

**词表**：12 情绪 + 36 意图，完整定义与 criteria 见 `intent-taxonomy.md`。

### H1. 意图分布（`intent_profile`）

对全量（或抽样窗口）逐条归类，统计**每一类意图的条数，按发送方分开**：

```json
"intent_profile": {
  "total_classified": 4120,
  "coverage": "全量 1541 条中 980 条可可靠归类（64%）",
  "caveat": "其余落在 other/unknown，未强行归类",
  "categories": [
    {"intent": "学术讨论", "me": 210, "them": 96, "evidence_level": "high",
     "evidence": [{"quote": "……", "date": "2026-09-27", "sender": "them"}]}
  ]
}
```

**只报非零类别**，按 `me + them` 降序。`coverage` 与 `caveat` 是**必填**——
覆盖率低不是失败，隐瞒覆盖率才是。

### H2. 三条硬规矩

1. **`academic` 不算冷淡。** 与 A5「回应四类」的既有口径一致：**讲技术属于「投入」**。
   对方跟你讨论代码、题目、论文，是给了你「对方没有的东西」，不是敷衍。
2. **四类关系敏感意图强制过 F5。** `attention` / `interest` / `invite_hint` / `flirt`
   命中 < 2 轴不得作为证据。详见 `intent-taxonomy.md` 第三节。
3. **不得用意图分布反推关系性质。** 「她 `care` 类不少」推不出「她喜欢你」——
   `care` 的 criteria 明确写了「**不自动表示恋好感**」。意图层是**描述**，不是**判断**。

### H3. 与 A5「回应四类」的接口

A5 判「回应」用四类（投入 / 应答 / 转开 / 没回）。映射关系：

| A5 四类 | 典型意图 |
|---------|---------|
| **投入**（给了对方没有的东西） | `academic` / `explain` / `advice` / `opinion` / `share` / `ask` |
| **应答**（只接住，内容是对方已确定的） | `acknowledge` / `answer` / `agree` / `thanks` |
| **转开** | `change` / `close` / `ease` |
| **没回** | 无对应意图（`msg_key` 不在 `per_message` 里 = pending） |

**这个映射是单向的**：意图 `academic` 支持判定为「投入」，但**反过来不成立**——
不能因为一次回应被归为「投入」，就说这段关系在升温。

### H4. 情绪分布（`language_patterns.emotion_distribution`）

用 12 情绪词表统计双方情绪构成，作为**辅助**写进 `language_patterns`：

```json
"emotion_distribution": [
  {"label": "平静", "me": 320, "them": 410},
  {"label": "调侃", "me": 96, "them": 58}
]
```

⚠️ **`calm`（平静）经常被误读成「冷淡」**。`calm` 是「无明显情绪」，是中性值，不是负向。
报告里若出现「对方 60% 是平静情绪」，**不得**把它解读为疏远信号。

> 情绪分布是**词表层**产物，与可选的 `affect`（句向量层）是两条独立链路，
> 不要互相校验也不要互相替代。`affect` 的边界见 `affect-limits.md`。
