# 爱情可以用二元隐空间表征吗？

> 这份文档是 `data/stats.json` 里 `affect` 段的**读法说明与边界声明**。
> 执行 Step 7 时如果读到了 `affect`（`status == "ok"`），**先读这一份**——
> 不然会把它当主指标用，而那正是它做不到的事。

**一句话**：能表征一部分。但**能表征的那部分，恰好不是最想知道的那部分**。

下面每一条都有实测数字，语料是一份 180 天 / 1243 条的私人微信记录。

---

## 一、它确实做到了的

| | 实测 |
|---|---|
| **逐条效价/唤醒是稳的** | 平行测量信度 **0.902**（把 10 对锚句劈成两半各建一条轴，两条轴投影相关 0.822，Spearman-Brown 校正到全长 0.902） |
| **两条轴接近正交** | 效价轴 · 唤醒轴 = **−0.13**。唤醒锚句的正负配平生效了 |
| **表面效度看得出来** | 最正端「恭喜恭喜 +0.226」「谢谢啦 +0.186」；最负端「我电脑坏了 −0.281」「我不想说了 −0.253」；唤醒最高「气死我了 +0.466」 |
| **它纠正了一句错话** | 旧报告说「她情绪平稳、你波动大」（词表口径）。实测**反了**：她的效价标准差 0.0985 > 他的 0.0832 |
| **有一条关系量站住了** | 会话内 `within_r(我→她) = +0.136`，会话聚类 bootstrap CI `[0.068, 0.267]` 不含 0 |

**方法出处**：semantic projection（Grand, Blank, Pereira & Fedorenko 2022, *Nature Human Behaviour*）——用**人读得懂的锚句**求方向，把句子投影上去。零新模型、可解释、可审计。

---

## 二、它做不到的（每一条都是撞出来的）

### 1. 语用标签：做不了，而且方向是反的

「敷衍」这类标签**不在情绪空间里**。四次尝试：

| 方案 | 实测 |
|---|---|
| 低效价窗口 | 11 条真敷衍的效价**全为正**（+0.035 ~ +0.118）；效价最低的一批（−0.173 ~ −0.060）是「没事」「不行」「别急」——**有情绪内容，反而不是敷衍**。召回 **0/11**，精确 **0/14** |
| 低唤醒 | 单个例子有效（「嗯」a=−0.054 vs「嗯嗯我超级想去！」a=+0.160），全组重叠 |
| 信息量（novelty） | 敷衍 0.6177 vs 短但不敷衍 0.6070，**差 −0.0107，方向反了** |
| 长度 | 真敷衍长度均值 1.5、被误判者 1.7——**差 0.2 字，分不开** |

**根因**：敷衍表达的是「我不想投入这段对话」——一个**关系信号**，不是心情。情绪测心情、信息量测内容，而敷衍测的是「这句话在关系里干什么」。**三个空间都不是它待的地方。**

**语境决定一切，这点已被数据证实**：同一句「加油」——

```
我: 从现在开始苦练摄影📸    她: 加油   ← 语境里是关心
我: 明天六级加油！          她: 加油   ← 仍是关心
```

孤立看这两个字，效价 +0.110、词表不收——**两种做法都对**，因为「它是不是敷衍」这个问题只有上文能回答。**任何脱离上下文的单句判定（词表或模型）都不成立。**

> **冷淡检测留在 `lexicon.DISMISSIVE_REPLIES` 白名单里。** 中文的敷衍是一小撮约定俗成的封闭词（嗯/哦/好/行），约定俗成的东西穷举就是对的。白名单命中 11 条、假阳性 **0**；而纯长度规则命中 106 条、假阳性 95 条（**90%**）。

### 2. 关系信号（投入度）：情绪测不出来，测出来的是**行为**

人工标了 240 个「burst 对」（A 连续说的若干条 → B 连续回的若干条），四类：投入 / 应答 / 转开 / 没回。

```
他→她    80 (67%)   35 (29%)     0     4
她→他    99 (83%)   16 (13%)     2     2
投入率差 +17.2%，会话聚类 bootstrap CI [+0.089, +0.242]   ← 不含 0
```

**这个结论是用人工标注得到的，不是用效价算出来的。** 反过来拿行为特征去逼近标签，最高的一个是：

```
B总字数       AUC 0.893      ← 长度
B最长一条      AUC 0.870
B条数         AUC 0.727
B有疑问        AUC 0.600
───────────
A有疑问        AUC 0.547      ← 对方那一侧全部 ≈ 0.5
A条数         AUC 0.470
A总字数        AUC 0.461
```

**两个结论**：① 预测「回得投不投入」的是**回的字数**，不是情绪。② **对方说了什么几乎不预测本方回多少**（A 侧全 ≈0.5）——所以两个方向可以直接比，不存在「他发的废话多所以她回得少」那种分母问题。

⚠️ 但字数与标签高度共线（定义明说「判新增不判长短」，实测新增必然要字数）。**不能用它去验证标签**，只能当一条独立的描述性指标。

### 3. 机制：问不出来，而且不是方法问题

三条路全部走死：

| 遍 | 做法 | 死因 |
|---|---|---|
| 一 | 三消息链中介（X=A(t₀) → M=B(t₁) → Y=B(t₂)） | **在选择变量上做了条件**——「B 连不连发第二条」正是被测的投入度维度，被排除的 295 个回合恰恰是低投入回应。证据：链子样本 c'=+0.159 **反而大于**全样本 +0.136 |
| 二 | 回 583 回合做同期中介 | **M 和 Y 共享同一个文本载体**——长度/延迟是那条消息的文本特征，Y 是那条消息的情绪投影，相关里有测量共享方差 |
| 三 | 调节模型（`Y ~ X + M + X*M`） | **continuity 和效价共享嵌入几何**——两条消息嵌入越近，效价投影在几何上必然越近 |

**第三遍那个坑值得单独记**，因为它暴露的是一个**默认工作流的系统性漏洞**：

> 用同一套嵌入同时构造预测变量和结果变量，就必然共享几何，共享的那部分会被读成效应。

实测：不做正交化时交互项 +0.171 / +0.226（两个方向都「显著」）；做完之后掉到 +0.087 / +0.148，**约一半是泄漏**，其中一个方向直接归零。已固化成 `affect.orthogonalise()`。

（细节：两条轴本身相关 r=−0.13，**必须先 Gram-Schmidt 正交化再投影**——按 v 再按 a 依次减会把 v 的分量重新引回来，实测残留 0.041，Gram-Schmidt 后 <1e−7。）

**⚠️ 而且 Gram-Schmidt 只保证数值正交，不保证语义正交。** 残差子空间里仍可能有别的情绪相关方向没被减掉。所以正交化之后残存的那点相关，只能读作「**来源不明**」，不能读作「去掉泄漏后还有真效应」。

### 4. 稀疏时序：日粒度是死的

```
182 天里只有 27 天双方都有消息
滞后 ±5 天时重叠样本只剩 6 个点
相邻滞后之间 r 能从 +0.83 翻到 −0.85
```

在那样的样本上，「取 |r| 最大」的规则会稳稳挑中最响的噪声，输出一句完全虚假的「她领先 5 天」。

**根子是密度不是方法。** 变点检测同理删掉——要让它跑起来就得在 68 天空洞上插值，而插值出来的斜坡会淹没真正的转折。

---

## 三、为什么

**① 语用的东西不在情绪空间里。** 情绪模型测的是「这句话的心情」；敷衍、试探、求和、推开这些是「这句话在关系里干什么」。后者需要的不是更好的模型，是**会话行为**这一层，而它不该用情绪去测。

**② 分析单位错配。** 闲聊语料里，**绝大多数消息的首要属性是会话功能**（提问、回答、接梗、汇报进度），情绪只是很淡的附带层：

```
我: 我明天要考试          效价 ≈ 0       功能是「告知」
她: 加油                  效价 +0.110    功能是「回应 + 鼓励」
我: 把你要打包的都拖进去   效价 ≈ 0       功能是「指令」
她: 好了                  效价 +0.117    功能是「汇报完成」
```

这些值全落在零点附近——不是因为它们「情绪中性」，是因为**这个量本来就不在它们身上**。用 95% 不携带该信息的消息去平均，信号当然被稀释成零。

**③ 锚句域 ≠ 目标域。** 锚句是第一人称情绪陈述（「我今天心情特别愉快」），语料是事务性闲聊（「把文件拖进去」「链接在哪儿」）。而且 **33% 的消息 ≤4 字**——「哈哈哈哈」「哦哦」这种文本上，「情绪」本身就没多少定义空间。

## 四、所以怎么用

| 用法 | 可以吗 |
|---|---|
| 逐条效价/唤醒坐标（`chat_history.txt` 行尾那个 `⟨+0.12/−0.03⟩`） | ✅ 信度 0.902，当**参考坐标** |
| 逐日走势曲线（报告里那张） | ✅ 只看走势，别读单点 |
| 两人的均值/标准差对比 | ✅ 描述性 |
| `within_r` 当成「她跟着你的情绪走」 | ⚠️ 可以说，但要说清它只有 r²≈2%，且 `between_r` 不得解释为传递 |
| 拿它替代词表做冷淡检测 | ❌ 召回 0/11，方向相反 |
| 拿它测「投入度」 | ❌ 投入度靠字数（AUC 0.893），那是行为不是情绪 |
| 拿它做中介 / 调节去问「为什么」 | ❌ 三条路全死，见上 |
| 拿它做日粒度时序 / 变点检测 | ❌ 密度不够 |

**它该是辅助层，不是主指标。** 主指标应该回到**会话行为**——谁发起、谁回应、回应里有没有新东西、沉默后谁先回来。这些的共同点是：单位是「**对什么做了什么**」，不是「感觉如何」。

而这一层里的 `within_r(我→她) = +0.136` 之所以是全部工作里唯一站住的，恰恰因为它**不是情绪量、是关系量**——「她的情绪在多大程度上随我的变」，一个必须成对才能定义的东西。
